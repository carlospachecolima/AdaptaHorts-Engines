# AdaptaHorts-Engines

Welcome to the central repository for our modular agents. This project contains a collection of independent agents developed in Python, each designed to perform specific tasks and solve problems across different domains.

## Repository Structure and Included Agents

The repository is divided into independent directories for each agent. Below are the currently available agents:

* **Adaptahorts Agent (`adaptahorts_agent/`)**
  * **Main file:** `pfbcia_agent.py`
  * **Description:** Agent focused on adaptation routines and PFBCIA processes. Check the [Adaptahorts README](./adaptahorts_agent/README.md) for specific setup and usage instructions.

* **AIGIS Mapping Agent (`aigis_mapping_agent/`)**
  * **Main file:** `aigis_agent.py`
  * **Description:** Agent dedicated to mapping tasks using the AIGIS system. Check the [AIGIS Mapping README](./aigis_mapping_agent/README.md) for more details.

* **Recommendation Agent (`recommendation_agent/`)**
  * **Main file:** `recommendation_agent.py`
  * **Description:** Agent specialized in generating and processing recommendations. Check the [Recommendation README](./recommendation_agent/README.md) for information on the recommendation engine's logic.

## Getting Started

Since each agent operates independently, installation requirements and instructions will vary.

1. Navigate to the desired agent's directory.
2. Read the specific `README.md` file located inside each agent's folder for instructions regarding dependencies, environment variables, and execution.
